=========
Tutorials
=========

These tutorials walk through the two core workflows in BoBa-T. Each notebook
contains instructions to run the example data, the expected output, and
explanations of the code.

* **Network construction** builds a transcription-factor network and should run
  in less than 10 minutes on a standard laptop.
* **Inference** fits regulatory rules and runs random walks; it should run in
  less than 30 minutes on a standard laptop.
